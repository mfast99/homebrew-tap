# homebrew-tap

Homebrew tap of [mfast99](https://github.com/mfast99).

```sh
brew install mfast99/tap/concourse-lint
```

The formulas and casks are written by the release workflows of the
projects (GoReleaser); do not edit them by hand.

- [concourse-lint](https://github.com/mfast99/concourse-lint): linter and language server for Concourse CI pipelines
